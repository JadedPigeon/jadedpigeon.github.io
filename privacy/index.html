The "rclone" Google app

The Google OAuth app named "rclone" is a personal tool. Its only user is its owner, JadedPigeon. It lets the open-source program rclone, running on the owner's own computer, back up the owner's files to the owner's own Google Drive.

  • Access: it asks only for the drive.file permission, so it can see and change only files that it created itself. It can't read anything else in Google Drive.
  • No collection: it doesn't collect, store, sell or share anyone's data. Files go directly between the owner's computer and Google Drive, and no other server is involved.
  • No other users: it isn't offered to anyone else.
